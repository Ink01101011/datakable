- Search: a one-word query is matched against each word of a cell by `ex-search`'s `fuzzyMode: 'word'` instead of DataKable's own per-row word split, with the same results and order. A one-typo query longer than 32 characters now matches. (#106)
- Search keystrokes are cheaper: DataKable no longer splits and scores every cell itself on each keystroke, and checks the query for spaces once per query instead of once per row. A one-word typo query at 100k rows takes about 30 % less time. (#96)
