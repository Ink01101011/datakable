- `<DataTable />`: body rows are memoised on their row data (`row.original`), index, issues and the `columns` array. Typing in the search box no longer renders every visible cell while the rows have not changed yet (each keystroke rendered all visible cells twice; now only rows that the search result changes render, once), and a parent re-render with the same props renders no cell. A new `columns` array (e.g. a `cell` renderer memoised on parent state) still renders every row again. The server HTML is unchanged. (#99)
- `onDiagnostic` calls raised while rendering on the server (e.g. `DK_INVALID_PAGINATION`, `DK_DUPLICATE_ROW_KEY`, `DK_SSR_ASYNC_DEFERRED`) are now delivered before `renderToString` returns, instead of in a microtask afterwards, so a server that reads its collected diagnostics right after the render sees all of them. On the client they are still delivered after the commit. (#105)
