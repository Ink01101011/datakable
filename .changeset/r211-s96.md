- With `fuzzyMaxDistance: 0`, a one-word search query no longer splits every cell into words: no word can match without fuzzy matching, so the matcher compares whole values only, with the same results. A keystroke at 100k rows went from about 71 ms to about 33 ms in that configuration; the default (fuzzy) configuration is unchanged. Tokenising once per data version and narrowing a lengthened query to the previous hits are left to `ex-search` (Ink01101011/ex-search#14, #15). (#96)
