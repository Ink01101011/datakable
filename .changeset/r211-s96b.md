- Search: `ex-search` goes from 1.2.0 to 1.2.1. With `fuzzyMaxDistance: 0`, a query that extends the previous one (`ad` → `ada`) now matches only the previous query's hits when ex-search's `canNarrow` proves the results are the same, checked on the trimmed, NFC, case-folded query DataKable scores: a keystroke at 100k rows goes from about 29 ms to about 1 ms. A one-word keystroke with fuzzy matching on reads each row once (ex-search 1.2.1 would otherwise read it twice to split it into words). The words of each cell are still split per keystroke: keeping ex-search 1.2.1's word index for every row would exceed the 5 MB memory budget at 100k rows. (#96)
