# DataKable diagnostics reference (moved)

The diagnostics reference moved to [How to fix → Diagnostics reference](how-to-fix/errors.md).
This page stays at its old address because every diagnostic DataKable prints links here
(`docs/errors.md#<code in lower case>`, the `docs` line of the console output): each code below
keeps its anchor and links to its full section — problem, common causes, fix and a real example.

Troubleshooting by symptom (no rows, sorting does nothing, a stuck loading state, …) is in
[How to fix](how-to-fix/README.md).
