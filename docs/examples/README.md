# Examples

A cookbook of complete recipes: each page solves one common table task end to end, with code you
can copy. Every TypeScript block is a compiled file, so the recipes match the released API.

## Recipes

Recipes coming:

- A zero-config table from an array
- Custom columns with formatted and nested values
- Search, filters and sorting wired to your own inputs
- Server-side data with a `fetcher`
- Validating rows with a schema
- Controlled state shared with the URL
- Server rendering with hydration
- A headless table without React
