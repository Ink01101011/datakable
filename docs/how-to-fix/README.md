# How to fix

Troubleshooting: what DataKable is telling you and how to fix it. Every problem DataKable detects
is a diagnostic with a stable `DK_*` code; every column mistake is a compile-time type error. Start
from the code or the error you see.

## Pages

- [Diagnostics reference](../errors.md) — every `DK_*` code: problem, common causes, fix and a
  real example. The `docs` link each diagnostic prints points to its section there.
- [Reading type errors](../reading-type-errors.md) — the type errors you are most likely to meet,
  and the line of each to read.
