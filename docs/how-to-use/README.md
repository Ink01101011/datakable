# How to use

Guides to DataKable's API, one topic per page: what the option or method is for, how to use it,
and what to watch out for. Each page builds on the [quick start](../../README.md#quick-start); the
package READMEs ([`datakable`](../../packages/datakable/README.md),
[`@datakable/react`](../../packages/react/README.md),
[`@datakable/core`](../../packages/core/README.md)) stay the API reference.

## Pages

Pages coming:

- Getting started: install, the zero-config table, picking an entry point
- Columns: dot-path keys, derived columns, `cell` and `format`
- Features: the default preset, choosing features, each feature's options
- Server data: `fetcher`, server mode, `refetch()`, the status model
- State: controlled state slices and listeners
- Schema validation: `schema` and `invalidRows`
- SSR: `initialData`, `createDeferred` / `startTable`, hydration
- Diagnostics: sinks, redaction, production builds, `explain()`
