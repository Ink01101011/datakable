## Design

- `getValue` accepts a dot-path string or a pre-split segment array (`compilePath`), so the pipeline
  (T09) splits once per column and the per-cell walk allocates nothing.
- A `null` / `undefined` / non-object (primitive, function) part-way through yields `undefined`.
  The leaf may be any value.
- Getter / Proxy throws are caught; `getValue` returns `undefined` and calls the optional
  `onError(error)` so the caller can report `DK_CALLBACK_FAILED` with its column + row `where`
  (`TODO(T06)`; the diagnostics catalog does not exist yet).
- `defaultFormat` follows the §4.3 table. Object / function (and arrays containing them) render
  `''` and call `onUnrenderable(value)` so the caller can emit `DK_UNRENDERABLE_VALUE` (`TODO(T06)`).
