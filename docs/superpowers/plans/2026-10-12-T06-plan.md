# T06 — errorBoundary + fallback registry + column:batch boundary (plan)

Spec §3.4, §8.3, §8.6. Builds on T04 (`intercept/runtime.ts` boundary slot) and T05 (catalog, hub).

## Files

| File | What |
|---|---|
| `intercept/fallbacks.ts` | fallback registry: `registerFallback(op, { describe, value })`, `getFallback(op)`; built-in entries per the §3.4 table; `FALLBACK` meta key for caller-supplied previous values |
| `intercept/classify.ts` | `CallbackError` (user callback threw, carries the slot), `classifyError(e)` → `DK_CALLBACK_FAILED` / `DK_INTERNAL` (top stack frame in DataKable code) / `DK_UNKNOWN` |
| `intercept/boundary.ts` | `errorBoundary` interceptor (`on: '*'`, `hot: true`): catch (sync + async) → classify → `ctx.emit` → registry fallback. `DatakableError` (config / strict / invariant) passes through |
| `intercept/cell-batch.ts` | `column:batch` cell boundary: `CellFailures` (numeric row record, no per-cell allocation), `runCells()` loop with inline try/catch, `CELL_FALLBACK` per slot, one `DK_CALLBACK_FAILED` per column per run |
| `intercept/codes.ts` | `DK_CALLBACK_FAILED`, `DK_UNKNOWN` definitions (declaration merge into `DiagnosticCatalog`) |
| `diagnostics/codes.ts` | extend `DK_INTERNAL`: optional `slot` / `errorName`, "likely a DataKable bug", prefilled issue link |
| `diagnostics/types.ts`, `build.ts` | additive: `operation` Location gets optional `slot` (formatWhere prints it) |
| `diagnostics/hub.ts` | minimal: a `DatakableError` (strict) thrown by a nested emit inside the chain is rethrown, not swallowed |
| `intercept/runtime.ts` | minimal: `report()` lets a `DatakableError` (strict) through instead of swallowing it |

## Tests first

- boundary: throw in every built-in op → code + `where` + registry fallback (sync, async, rejected promise).
- classification: CallbackError → DK_CALLBACK_FAILED (`where` = slot); own-frame Error → DK_INTERNAL; foreign frame / non-Error → DK_UNKNOWN.
- DatakableConfigError from `table:init` rethrown; strict hub + error-level emit inside an op throws `DatakableError`; strict + failing interceptor on `diagnostic:emit` throws `DatakableError` (DK_INTERCEPTOR_FAILED) out of `hub.emit`.
- cell batch: per-slot fallbacks, one diagnostic per column with count + sample rows, no emit when clean.
- catalog: new codes have non-empty where/problem/impact/fix.
