# T14 — Feature `sorting` (plan)

Spec §6.4 (sorting), §3.3 (feature contract), §4.1 (`sortable` / `sortFn` / `sortBy`), §9.1 (index
pipeline, column cache). Depends on T08 (`defineFeature`), T09 (runner, column cache), T10
(`defineOptions`).

## Goal

`sorting()` — a `stage: 'sort'` feature with state `{ by: { id, desc }[] }`, `toggleSort(id, { multi })`
cycling asc → desc → none, and a stable comparator over the `Uint32Array` index (never the data):
nulls / `NaN` / invalid `Date` last in both directions, mixed types by type rank, strings through one
`Intl.Collator(locale, { numeric: true })`, column `sortFn` / `sortBy` overrides. An object column
with `sortable: true` needs `sortFn` or `sortBy` (compile error).

## Steps (test-first)

1. `features/sorting/sorting.test.ts` (runtime) and `sorting.test-d.ts` (types) — failing first.
2. `features/sorting/compare.ts` — `typeRank`, `compareValues` (default comparator), `isMissing`.
3. `features/sorting/sorting.ts` — `sorting(opts)`: options schema (`locale`), `initialState`,
   `createApi` (`toggleSort`, `setSorting`, `clearSorting`, `getSortDirection`), `rowModel`:
   resolves each entry's values once per data (column cache → `Float64Array` fast path; `sortBy`
   values cached per data + column; path read for ids that are not columns), builds one comparator
   over row indices, sorts a copy of `indices` with native stable sort. A throwing `sortFn` /
   `sortBy` → `DK_CALLBACK_FAILED` (`where` = `columns[i].sortFn|sortBy`), that column falls back to
   the default comparator / `undefined` key.
4. `column/column-def.ts` — additive: `SortReq` on key columns whose value has no default order.
5. `index.ts` — `export * from './features/sorting'`.

## Out of scope

- `algorithm: 'auto'`, exsorted tim / radix / counting, `sortAlgorithm` / `algorithm` overrides,
  `DK_SORT_STRATEGY`, `DK_SORT_COMPARATOR_INVALID` — T15 (this unit always uses native
  `Array.prototype.sort`, which §6.4 already prescribes for strings, floats, multi-column and
  `sortFn`).
- `mode: 'server'` — T21. `autoResetPageIndex` on sort change — T20. Header UI / `aria-sort` — T33.
- `DK_ENV_FALLBACK` for a missing `Intl.Collator` locale (code not in the catalog yet).
