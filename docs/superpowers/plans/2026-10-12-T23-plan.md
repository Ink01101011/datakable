# T23 — Feature `validity` + `row.issues` / `getCellIssues` path matching — plan

Spec §6.2, §5.1. Depends on T13, T22.

## Scope
- `features/validity/`: `validity()` feature, stage `filter` (after `columnFilters` when listed
  after it). State `'all' | 'valid' | 'invalid'` (default `'all'`); API `setValidity(v)`.
  - Active only with `schema` + `invalidRows: 'flag'`. Otherwise its `rowModel` passes the input
    through and a non-`'all'` value emits `DK_OPTION_NO_EFFECT` (once per input / value, from the
    step, so API, `setState`, `initialState` and controlled state are all covered).
  - A slice that is not one of the three values reads as `'all'` and emits
    `DK_INVALID_VALIDITY` (feature-owned code); `setValidity` with a bad value is ignored + the
    same code.
- `RowModelContext.flagged?` (additive): under flag mode, the issues of a row by data index
  (`undefined` for a valid row); absent in every other mode. Filled by the runner from a new
  optional `PipelineHost.flagMode` (set once in `createTable`).
- `getCellIssues` path matching, segment-wise (no string join, no per-call allocation unless an
  issue matches): `issuePathTouches(path, segments)` in `ingest/schema.ts` (next to T22's helpers).
  - issue path and column key segments equal on their common prefix (equal, issue under the
    column, column under the issue); `{ key }` segments and numeric keys compare as strings; a
    symbol segment never matches; a dotted single segment (`{ key: 'a.b' }`) does not match the
    column `a.b` (two segments).
  - row-level issues (no / empty path, or a path that throws when read) touch every column,
    accessor columns included; accessor columns get only those.
- `InvalidCellContext.issues` (additive): the cell's issues (`row.getCellIssues(column)`).
- Exports from `packages/core/src/index.ts` (added lines only).

## Steps (test-first)

2. `features/validity/validity.test-d.ts`: state / API typing.
3. `ingest/cell-issues.test.ts`: issue→column mapping matrix (equal, nested both ways, siblings,

   dotted segment, root-level issues incl. accessor columns, crash synthetic issue).
4. Implement; gate; re-run memory test (100k ≈ 2.1 MB).
