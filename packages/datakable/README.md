# datakable

Type-safe generic DataTable for React. Zero-config by default, headless when you need it.

> 🚧 Early development — the API is not stable yet. See the [repository](https://github.com/Ink01101011/datakable) for progress.

## Packages

| Package | Purpose |
| --- | --- |
| `datakable` | Batteries-included entry — re-exports `@datakable/react`; `datakable/core` re-exports the headless core |
| `@datakable/react` | `useDataTable` hook + `<DataTable />` component |
| `@datakable/core` | Headless, framework-agnostic state / sort / filter / types |
